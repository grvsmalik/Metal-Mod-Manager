# Metal Mod Manager brand

The master files for the Metal Mod Manager logo, icon and banners. `brand-guide.pdf` (also `brand-guide.png`) explains how to use them: clear space, minimum sizes, colours, typography, and correct and incorrect use.

| Files | Use |
|---|---|
| `logo-mark-*.svg` | The mark on its own. Below 24 px use `logo-mark-small-*.svg`. |
| `wordmark-*.svg`, `wordmark-short-*.svg` | "Metal Mod Manager" and the short form "Metal" |
| `lockup-horizontal-*.svg`, `lockup-stacked-*.svg` | Mark and wordmark together |
| `app-icon.svg`, `app-icon-small*.svg`, `app-icon-*.png`, `app-icon.ico` | The application icon (the `.ico` holds 16–256 px) |
| `github-banner-*.png`, `github-social-preview.png` | README banner and the repository's social preview |
| `nexus-registration-logo.png` | The logo sent with the Nexus Mods API registration |

Suffixes: `-color` for dark backgrounds (the default), `-color-light` for light backgrounds, `-white` and `-dark` for one colour.
